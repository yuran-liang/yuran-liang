## Projects

### [CppND-Capstone-SLAM](https://github.com/yuran-liang/CppND-Capstone-SLAM)
Lidar SLAM without ROS: a modern C++17 rewrite of [A-LOAM](https://github.com/HKUST-Aerial-Robotics/A-LOAM)
(LOAM, Zhang & Singh, RSS 2014) with feature extraction, scan-to-scan odometry and
scan-to-map refinement solved with Ceres, plus a PCL-based viewer for the map and trajectory.
Runs on the KITTI odometry dataset.

`C++17` `PCL` `Ceres Solver` `Eigen` `CMake`

### [smart-home](https://github.com/yuran-liang/smart-home)
Home automation around a Raspberry Pi and MQTT: an ESP8266 room sensor, a Python
controller that drives a Bluetooth radiator thermostat with a P-controller,
and a Docker Compose stack with Home Assistant and Zigbee2MQTT.

`ESP8266` `PlatformIO` `Python` `MQTT` `Docker` `Home Assistant`
